Подбор endpoint

Проверка доступности адресов Cloudflare с роутера (TCP + TLS на порту 443). Адреса ниже — предположительные из диапазонов Cloudflare WARP, не гарантированные. usque работает по QUIC (UDP), поэтому замер ориентировочный: он показывает достижимость и задержку, но не гарантирует работу MASQUE. Замер идёт по обычному маршруту роутера.
